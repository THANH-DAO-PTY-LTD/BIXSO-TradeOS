# Changelog

## 0.2.0 · 2026-11-28

- Breaking: renamed to BIXSO Sourcing OS (was BIXSO TradeOS). The command is now `sourcingos` and the data variable `SOURCINGOS_DATA`. Saved files keep their format.
- Docs: trademark policy (TRADEMARKS.md), code of conduct, DCO sign-off for contributions with a pull-request check, Dependabot, community and BIXSO OS family links in the README, and package metadata.
- CI runs on Node.js 22 and 24 (the supported range in `engines`), with GitHub Actions v7.
