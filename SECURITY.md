# Security policy

If you find a security issue, use [Report a vulnerability](https://github.com/THANH-DAO-PTY-LTD/BIXSO-Sourcing-OS/security/advisories/new) to open a private report. Include the affected version, environment, impact and a minimal example using fictional data. Keep customer records and secrets out of the report. Use public issues for ordinary bugs and feedback.

Reports about bypassing maker-checker, lineage, organisation isolation or idempotency are in scope. This is an early project maintained on a best-effort basis.
