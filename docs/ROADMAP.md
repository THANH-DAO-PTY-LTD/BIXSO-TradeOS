# BIXSO Sourcing OS roadmap

**Updated 28 November 2026.** Part of the [BIXSO OS roadmap](https://github.com/THANH-DAO-PTY-LTD/.github/blob/main/ROADMAP.md). This project is the open concept and lite code for the rules in [Bixsourcing](https://bixsourcing.web.app).

## Now: in this repository

- 19 explicit workflows from organisation setup to delivered order
- Maker-checker approvals, lineage checks and organisation isolation
- A SHA-256 receipt for every step; idempotent, versioned writes

## Next: help wanted

- Export a record's history as CSV ([#4](https://github.com/THANH-DAO-PTY-LTD/BIXSO-Sourcing-OS/issues/4))
- A local stand-in for the server-only steps, so all 19 flows can be completed from the command line
- More examples: award, contract and delivery

Pick one up, or comment on the issue before you start. Items without an issue are open for an idea or a pull request.

## Questions for people who do this work

- Which approval steps does your business actually use?
- What should block a quotation that the current rules allow?

Answer in an issue using **Share an idea**, or on [r/BIXSO](https://www.reddit.com/r/BIXSO/).

## Not planned in this repository

- Moving money, legal signatures, identity checks and counterparty matching.

This is a direction, not a promise of dates. How decisions are made: [GOVERNANCE](https://github.com/THANH-DAO-PTY-LTD/.github/blob/main/GOVERNANCE.md).
